## Как рекрутеры находят PHP-разработчиков

### rabota.by / hh.ru

| Механизм | Пример запроса | Где ищет |
|----------|---------------|----------|
| Ключевые слова | `PHP Laravel` | Заголовок, навыки, опыт, «О себе» |
| Булевы запросы | `PHP AND (MODX OR ModX)` | Все текстовые поля |
| Фильтры по навыкам | Навык: Laravel, уровень: средний+ | Раздел «Навыки» |
| Поиск в конкретных полях | `Laravel` в поле «в названии должности» | Заголовок резюме |
| Точная фраза | `"REST API"` | Все текстовые поля |
| Комбинированные | `PHP AND Docker AND (Laravel OR Symfony)` | Все текстовые поля |

### LinkedIn Recruiter

- **Headline** — самое важное поле для поискового совпадения
- **Skills** — LinkedIn сильно весит этот раздел при ранжировании
- **About + Experience** — полнотекстовый поиск
- **Skill Assessments** — пройденные тесты поднимают профиль в выдаче
- **Активность** (посты, комментарии) — увеличивает видимость
- **Полнота профиля** — влияет на ранжирование

## Критические проблемы

### 1. Уровни навыков на rabota.by отсекают вас из фильтров

| Навык | Сейчас | Надо | Почему |
|-------|--------|------|--------|
| ООП | Базовый | **Средний** | Рекрутер с фильтром «ООП: средний+» вас не видит. Базовый ООП = «не умеет программировать» |
| Laravel | Базовый | **Средний** | У вас есть коммерческий проект на Laravel — это не «базовый» |
| CSS | Базовый | **Средний** | Вы верстаете на Tailwind и Bootstrap |
| MySQL | Не указан | **Средний** | Без уровня — рекрутер не может фильтровать |
| WordPress | Не указан | **Средний** | Аналогично |
| jQuery | Не указан | **Средний** | Аналогично |
| PHP7 | Не указан | Удалить, заменить на **PHP 8** | Устаревшая версия |

### 2. Отсутствуют ключевые слова, по которым ищут

Рекрутер вбивает `PHP AND REST API` — вас нет.  
`PHP AND Docker` — вас нет.  
`Laravel AND Eloquent` — вас нет.

**Добавить на обе платформы:**

| Категория | Ключевые слова |
|-----------|---------------|
| PHP-экосистема | PHP 8, Composer, PSR стандарты |
| Laravel-стек | Eloquent ORM, Blade, Artisan, Migrations, Laravel Routing |
| API | REST API, RESTful |
| MODX | MODX Revolution, MODX Revo, pdoTools, miniShop2, Fenom |
| БД | SQL (отдельно от MySQL) |
| DevOps | Docker, Linux, Nginx, Apache, SSH |
| Frontend | Tailwind CSS, Адаптивная вёрстка, Responsive design |
| Инструменты | GitHub, GitLab |
| Практики | SOLID |
| SEO | SEO-оптимизация, Техническое SEO |

### 3. Заголовок резюме на rabota.by слишком общий

- **Сейчас:** `PHP-разработчик`
- **Надо:** `PHP-разработчик (MODX / Laravel)` или `PHP / Laravel / MODX разработчик`

### 4. Тесты подтверждения навыков устарели

Перепройти: ООП, HTML, PHP, CSS, Git, JavaScript.  
Профили с актуальными тестами ранжируются выше.

## Серьёзные проблемы

### 5. Описание опыта — плоский список без результатов

**Сейчас:**
> - правки и доработки функционала существующих проектов на Modx, Wordpress, Bitrix, open cart

**Как переписать:**
> - Разработал с нуля 7+ коммерческих сайтов на MODX Revolution (pdoTools, Fenom, miniShop2)
> - Участвовал в разработке e-commerce проекта на Laravel + Tailwind CSS: Eloquent ORM, Blade, миграции
> - Параллельно вёл 20+ проектов — доработка функционала, SEO-оптимизация, интеграция аналитики
> - Настройка серверного окружения: хостинги, DNS, SSL, cron, деплой

### 6. LinkedIn — навыки низкой ценности в топе

**Удалить:** Session, Cookie, Работа с файлами, Работа с хостингом, DNS  
**Добавить:** REST API, Docker, Eloquent, SOLID, PHP 8, Tailwind CSS, SQL  
**Закрепить в топ-3:** PHP, Laravel, MODX  
**Пройти тесты:** PHP, MySQL, Git, JavaScript (пройден только CSS)

### 7. Секция «О себе» — противоречия

- Пишете «2 года опыта», а в шапке «4 года 3 месяца»
- Дублируете навыки без добавления ценности
- Телеграм/телефон внизу — избыточно

### 8. Нет ссылки на GitHub / портфолио

- Создать/оформить GitHub
- Заполнить секцию «Портфолио» на rabota.by
- Довести до ума Laravel-проект book-shop

### 9. LinkedIn headline можно усилить

- **Сейчас:** `PHP Developer | MODX / Laravel`
